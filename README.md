# MediCore Health Technologies
### Enterprise Healthcare AI Security & Governance Assessment

**Project Type:** Simulated Enterprise Cybersecurity Assessment  
**Role:** IT Risk & Cybersecurity Analyst  
**Industry:** Healthcare Technology  
**Environment:** AWS Cloud | Healthcare SaaS | Generative AI | Third-Party Integrations

---

## 1. Project Overview

This project simulates an enterprise cybersecurity and IT risk assessment for a healthcare technology company operating an AWS-hosted SaaS platform with integrated generative AI capabilities.

The assessment examines the organization's security posture, identifies control deficiencies, evaluates technology and vendor risks, and develops practical remediation recommendations.

The project is designed to reflect the responsibilities of an IT Risk Analyst working with security, cloud engineering, compliance, privacy, legal, and executive stakeholders.

## 2. Business Scenario

MediCore Health Technologies is a fictional healthcare technology company providing cloud-based software to healthcare organizations.

**Simulated company profile:**
- 180 employees
- 35 healthcare customers
- 8,000 healthcare professional users
- $32 million annual revenue
- AWS-hosted SaaS environment
- External generative AI / LLM integration
- Processes electronic protected health information (ePHI)

The company is preparing for a major hospital enterprise contract and must evaluate its security controls, third-party dependencies, AI risks, and healthcare data protection practices.

## 3. Assessment Objectives

The engagement focuses on:

1. Enterprise cybersecurity risk identification and prioritization.
2. AWS cloud security architecture and configuration review.
3. Identity and access management (IAM) assessment.
4. Security control assessment using NIST guidance.
5. HIPAA Security Rule gap analysis.
6. Third-party vendor and SOC 2 risk assessment.
7. AI governance and large language model security.
8. Incident response and ransomware preparedness.
9. Remediation planning and executive risk reporting.

## 5. Technical Environment

The simulated environment includes:

- Centralized logging and monitoring

- External AI model provider
- Third-party software and service providers
- Healthcare data processing workflows

## 6. Key Risk Scenarios

The assessment investigates simulated security concerns, including:

- Excessive administrative privileges.
- Inconsistent multifactor authentication enforcement.
- Potentially exposed cloud storage configurations.
- Incomplete centralized security logging.
- Weak backup isolation and ransomware resilience.
- Inadequate third-party vendor oversight.
- Unclear AI data retention and deletion practices.
- Prompt injection and sensitive information disclosure.
- Insufficient incident response evidence and testing.

These are assessment scenarios, not verified findings about a real organization.
